# Lion Voice

Статическая страница для перевода и озвучивания текста. По умолчанию использует голоса браузера. Можно выбрать OpenAI для более естественной речи.

## Локальные голоса

В macOS откройте «Системные настройки → Универсальный доступ → Озвучивание содержимого» и загрузите дополнительные русские голоса. Затем перезагрузите страницу. Приложение по умолчанию покажет только доступные русские голоса и запомнит выбор в этом браузере. Английские можно включить отдельным переключателем. Количество локальных русских голосов зависит от macOS и браузера.

## OpenAI TTS

Страница на GitHub Pages не может безопасно хранить ключ API. Для облачного режима предусмотрен Cloudflare Worker в папке `worker/`. В режиме OpenAI доступны 13 голосов: их названия английские, но они могут озвучивать русский текст. Качество русского произношения стоит сравнить на своих примерах.

1. Установите [Wrangler](https://developers.cloudflare.com/workers/wrangler/install-and-update/) и войдите в Cloudflare: `npx wrangler login`.
2. В папке `worker/` выполните `npx wrangler secret put OPENAI_API_KEY` и вставьте ключ OpenAI. Ключ сохраняется как секрет Worker и не попадает в репозиторий.
3. Там же выполните `npx wrangler deploy`. Адрес опубликованного Worker уже указан на странице по умолчанию: `https://lion-voice-tts.stas-pintea-lion-voice.workers.dev`.
4. На странице переключите способ озвучивания на OpenAI.

Worker разрешает запросы со страницы `https://stas-pintea.github.io` и с локального сервера на порту 8000. При другом домене обновите `ALLOWED_ORIGINS` в `worker/src/index.js`. Каждый запрос отправляет текст в OpenAI и может стоить денег. Ограничение по `Origin` защищает браузерные вызовы, но не заменяет защиту от прямых запросов к публичному Worker. Worker ограничивает запросы до 10 в минуту на IP в каждой точке Cloudflare; дополнительно задайте лимит расходов в OpenAI. Текущий лимит — 2000 символов за запрос. Облачный режим требует интернет; подсветка слов оценивается по длительности аудио и может не совпадать с произношением.
