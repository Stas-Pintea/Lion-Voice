# Lion Voice

Бесплатная страница для перевода и озвучивания текста. Работает на GitHub Pages: https://stas-pintea.github.io/Lion-Voice/

## Голоса

- **Mac / браузер:** использует установленные в системе русские голоса. Чтобы добавить доступные голоса, откройте «Системные настройки → Универсальный доступ → Озвучивание содержимого» и загрузите их, затем перезагрузите страницу. Английские голоса скрыты по умолчанию.
- **Русские нейроголоса:** четыре голоса Piper — Ирина, Денис, Дмитрий и Руслан. Озвучка выполняется на устройстве, без аккаунта, API-ключа и оплаты. При первом выборе голоса браузер скачивает его модель из Hugging Face; это может занять время и использовать десятки мегабайт трафика. Затем модель хранится в данных сайта в браузере. Для первого запуска нужен интернет.

Подсветка слов в режиме Piper приблизительная: она рассчитывается по длительности аудио и может отставать от произношения.

## Сборка

`npm install` и `npm run build` собирают `assets/piper.js` из `src/piper-entry.js`. Собранные файлы хранятся в репозитории, чтобы GitHub Pages мог обслуживать сайт без отдельного процесса сборки.
